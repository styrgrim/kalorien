# Winter Arc

Kalorien-Countdown

Kostenloser Abnehm-Rechner für das iPhone. Er zählt dein Kaloriendefizit bis zum Zielgewicht herunter und nutzt dafür deine Daten aus Apple Health (Apple Watch, Ernährungs-App, Waage).

- Einrichtung direkt auf der Seite, ca. 5 Minuten
- Tägliche Übernahme per Kurzbefehl, ein Tipp auf „Senden“
- Kalender mit Tageszielen, Prognose, „Was wäre, wenn“-Rechner
- Abgleich mit der Waage nach drei Wochen
- Alle Daten bleiben auf dem eigenen Gerät (kein Konto, kein Server)

Hobbyprojekt, keine medizinische Beratung.
